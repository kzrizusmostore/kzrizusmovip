🛡️ Apakah Zusmo Shadow aman digunakan?

YA, 100% aman. Zusmo Shadow menggunakan sistem VPN/Proxy dan tidak memodifikasi file game pengguna.

🔌 Apa saja grup API yang tersedia di layanan FF?

Layanan API pihak ketiga yang dipakai sebagian fitur di sini punya beberapa grup endpoint. Halaman ini hanya mengaktifkan grup yang bersifat lookup info publik:

  • Ban Check (/bancheck) — cek status banned UID, sudah aktif di fitur "Cek Banned".
  • Free Fire Info (/freefireinfo) — profil publik pemain, sudah aktif di fitur "Info Pemain".
  • Friends (/friends) — FRIEND Tools sudah terintegrasi: daftar teman, add/remove, star/unstar, dan set/remove alias. Guild (/guild), Banner (/banner), Craftlands (/craftlands), Long Bio (/longbio), Outfits (/outfits) mengikuti integrasi fitur masing-masing.
  • JWT Tools — sudah terintegrasi di FF Tools: Access Token/Guest ke JWT, JWT Only, EAT Decode, JWT Decode, dan proses massal.

Bind Tools, JWT Tools, FRIEND Tools, CRAFTLAND, dan EQUIP ITEM sekarang sudah terintegrasi di FF Tools. EQUIP ITEM memakai /additem/additem untuk memasang satu atau banyak Item ID lewat JWT. CRAFTLAND menggabungkan Quick Info /craftlands/info dan Full Detail /craftlands/map_details dalam satu tools. FRIEND Tools memakai /friends/list, /friends/friend_action, /friends/addstar, /friends/removestar, /friends/setalias, dan /friends/removealias. JWT Tools tetap mencakup generator, EAT decode, JWT decode, dan proses massal.

Kenapa token ditolak atau kedaluwarsa?
JWT punya masa berlaku jika memuat kolom exp. Siapkan token baru dari metode login yang sama. Pemeriksaan format di halaman ini bukan verifikasi keaslian token. Pastikan juga jam perangkat benar dan token berasal dari akun yang hendak diubah.
Bedanya API key, EAT, Access Token, dan JWT?
API key memberi aplikasi akses ke layanan penyedia. EAT ditukar menjadi Access Token. Access Token merupakan data login akun yang diterima layanan. JWT / BearerAuth adalah token yang dipakai untuk permintaan bio. Ketiganya tidak bisa saling menggantikan. API key sudah menggunakan konfigurasi aplikasi; kamu tidak perlu menempelkannya sebagai token.

        Apa itu Guest Register?
        Guest Register adalah utility berbasis terminal untuk membuat record akun guest Free Fire. Tool dijalankan melalui Termux di Android dan hasilnya disimpan sebagai file JSON.
        VPN WAJIB AKTIFJangan mulai proses Guest Register sebelum VPN aktif.
        Yang Dibutuhkan
        Android + Termux
        Python 3.9 atau lebih baru
        Koneksi internet aktif
        VPN aktif
        Izin penyimpanan Android
        Cara Menggunakan
        1
        Unduh GuestRegister
        Tekan tombol Unduh GuestRegister pada halaman utama Guest Register.
        2
        Buka Termux dan izinkan penyimpanan
        termux-setup-storage
        3
        Install dependency
        pip install requests pycryptodome rich
        4
        Jalankan tool
        chmod +x GuestRegister
        ./GuestRegister
        5
        Isi data Guest Register
        Pilih menu Guest Register, lalu masukkan nama akun, region, jumlah akun, nama file, dan folder penyimpanan. Periksa ringkasan lalu konfirmasi untuk memulai.
        Lokasi Hasil
        Hasil disimpan sebagai file JSON. Dokumentasi tool juga menyebut hasil dapat disalin ke:
        /storage/emulated/0/BhauXGuestRegister/<nama-file>.json
        Region yang Didukung
        MEINDIDVNTHBDPKTWEUROPERUNASACBRSGUSCIS
        Default region pada tool adalah BD.
        Jika Tidak Bisa Jalan
        Permission denied
        chmod +x GuestRegister
        Module Python tidak ditemukan
        Jalankan ulang instalasi dependency:
        pip install -r requirements.txt

        Status approval diperiksa otomatis setiap lima detik. Biarkan tool tetap terbuka atau jalankan kembali nanti.
