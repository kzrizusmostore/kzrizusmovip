KZRIZUSMO FF — Netlify

1. Ekstrak ZIP ini.
2. Masukkan kembali folder zusmo-asset dari proyek asli jika ada.
3. Unggah seluruh folder kzrizusmo-ff ke bagian Deploys pada situs Netlify yang sama.
   index.html, _redirects, _headers, css, dan js harus berada di akar hasil deploy.
4. Tunggu deploy berstatus Published lalu muat ulang website.

Jangan unggah index.html saja. File _redirects menghubungkan Like Gratis ke API melalui Netlify. Tidak perlu menjalankan Node.js di Netlify.

Pengujian koneksi tanpa menambahkan like:
Buka /api/ff-likes/like di domain website. Jika proxy aktif, API mengembalikan JSON error Invalid API key (bukan halaman 404 atau HTML website). Ini hanya memeriksa koneksi; bukan bukti pengiriman like berhasil.

Like Gratis menampilkan jumlah sebelum, sesudah, dan like yang ditambahkan sesuai hasil API. Status 2 dengan tambahan 0 berarti tidak ada like baru. Tidak ada percobaan ulang otomatis. Netlify membatasi waktu proxy; jika layanan lambat atau koneksi terputus, periksa like di game sebelum mengirim ulang.

Versi index.html lengkap yang dikirim terpisah dapat menggantikan index.html dalam folder ini. Tetap sertakan _redirects dan _headers saat deploy.

Opsional lokal: Node.js 18+, npm start, buka http://localhost:3000.

Aset lokal zusmo-asset tidak tersedia pada sumber yang diterima; gunakan aset proyek asli. Paket berbayar tetap memakai harga dan alur pemesanan yang sudah ada.
